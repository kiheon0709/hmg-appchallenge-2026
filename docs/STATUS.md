## 2026-10-29 접수 메일 문의 (11-04 현재 답변 없음, FAQ·공지 갱신도 없음)

1. 주행 중 NO_SETUP이 설정 UI만 막는지, Vehicle set 호출(`setAmbientLightBrightnessColor`, `setHvacFanSpeed`)까지 막는지 — **5번·1번의 성패를 가름**
2. Playground SDK 탭 Vehicle Control 'Coming Soon'과 설명회 "전부 사용 가능" 발언의 관계
3. NaviHelper 남은 시간·거리 실시간 수신 여부 (`TripInfo`/`DrivingInfo` 클래스는 있으나 필드 문서 미확인)
4. 차속 획득 방법 (Vehicle 19개 도메인에 차속 없음)
5. 자체 음원 재생 시 오디오 포커스, TTS 덕킹
6. 2차 PT 시연 환경 (노트북·에뮬레이터 지참, 앰비언트 시각화)

대응: 1·2번만 짧게 재문의 권장. 답을 기다리지 않고 "주행 중엔 음악만, 조명은 정차 중" 버전으로 개발 시작하고, 에뮬레이터에서 D단 상태로 set 호출을 직접 시험.

## 5번 아이디어 보완 과제

- 사용자 근거 리서치: 상황별 드라이브 음악 수요(예: 비 오는 날 드라이브 플레이리스트), 운전 중 선곡 불편, 제네시스 무드 큐레이터 반응
- 차별화: 제네시스 "무드 큐레이터"(사용자가 모드 선택) vs MooDrive(차가 상황을 감지해 자동 전환 + 도착 시간 맞춤 + 취향 학습)
- 주행모드 연동 자동 조명 색(`setAmbientColorAutoByDriveModeEnabled`)은 앱 실행 중 off, 종료 시 원복
- Wiper API는 State/Switch만 있음. 강도 단계 값은 미확인

## 작업 환경 메모

- Pleos 에뮬레이터는 Mac arm64 이미지라 클라우드에서 실행 불가 → 실행·녹화는 로컬 맥에서.
- Playground 프로젝트 ID(Key)는 저장소에 커밋하지 말 것 (`local.properties` 등 사용).
