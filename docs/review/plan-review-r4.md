## 3. 남은 약점 상위 5개 (감점 크기 순)

### W1. 사업성: 1단계에서 살아남을 이유·진입장벽·단가 근거가 없음 (사업성 −0.9, 평균 −0.25)

### W3. 음성 응답 흐름에 반대 해석이 남음, 특히 휴게소 질문 (기술활용성 −0.2, 안전 신뢰도 −)

  - "그러자"·"그럴까"·"들를게"·"가 보자" → UNKNOWN.
  - "졸리면 말할게"(거절의 뜻) → REST_STOP → **경유지 추가**.
- 질문이 없을 때 "졸린데 신나는 노래 틀어줘"는 확인 없이 곧바로 경유지를 추가합니다(`answerRestStop(true)`). 기획서 5-3의 "휴식 제안"과 다릅니다.
- "별로 안 졸려" → DISLIKE이고, 지금 곡을 감점하고 넘깁니다.

- **고칠 것**
  1. 질문 대기 중에는 LIKE("좋아/좋아요")와 "그러자·그럴까·들를게·가 보자"를 YES로 봅니다. 곡 평가는 "이 노래"가 함께 있을 때만 합니다.
  2. 조건절("~면", "~하면")에 붙은 졸음 어휘는 REST_STOP으로 보지 않습니다. "별로"가 "안 X"와 같이 오면 DISLIKE가 아니라 X의 부정으로 봅니다.
  3. 질문 밖의 REST_STOP은 바로 추가하지 말고 SuggestRestStop(확인 질문)으로 바꿉니다.
  4. 졸음 어휘에 "눈이 감·잠 와·잠이 와·쉬자"를, SKIP에 "바꿔·다른 노래·다른 거"를 추가합니다.
