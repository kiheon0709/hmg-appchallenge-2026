# 타비(TABI) 화면 도감 (2026-11-15)

타비의 기능과 경우별 화면을 캡처한 기록이에요. 평가가 아니라 "어떤 경우에 어떤 화면이 나오고, 타비가 무슨 말을 하는지"를 남긴 것이에요.

- 목록과 띄우는 방법: `2026-11-15_screen-catalog-plan.md`
- 찍으면서 본 문제: `2026-11-15_screen-catalog-issues.md`
- 노션: [타비 화면 도감](https://app.notion.com/p/4193aab653418178af0ed6c58b49f781) ("타비 (TABI) — 최종 정리" 아래, 절별 하위 페이지 8개. 캡처는 절마다 번호 붙은 묶음 이미지로 올림)
- 캡처: `shots-catalog/` 159장. 앱 창(1682×1210)만 잘라 1200 px로 줄였어요.

## 빌드와 환경

| 표기 | 빌드 | 쓴 곳 |
| --- | --- | --- |
| `v22` | `apk/MoodLab_TABI_release.apk`(커밋 `034da78`, 타비 캐릭터) | 첫 실행 소개·권한·차종 고르기·처음 홈(주간) |
| `v23` | 커밋 `8991efa`의 debug 빌드(캐릭터 + 주아체 글꼴) | 질문과 대화, 훈련 공통(준비·시작 판·힌트·시간 초과·실패), 야간 홈 |
| 표기 없음 | 커밋 `eabeedd`(v21)의 debug 빌드 | 상황 18개, 장소·시간대, 가는 길, 돌발·교관·미니게임, 주행 코치, 리뷰 |

- v21 캡처는 캐릭터가 들어가기 전이라 타비 표식이 옛 그림이고 글꼴도 기본 글꼴이에요. 장면과 판의 배치는 v23과 같아요.
- 에뮬레이터는 `emulator-5556`(Pleos Connect)이에요. 차량 신호는 Virtual Console(`127.0.0.1:8089`)로 실제 와이퍼·전조등·브레이크·깜빡이·창문·공조·기어 값을 넣었어요.
- 위치(보호구역·속도)는 `adb emu geo fix`로 넣었어요.
- debug 명령으로 쓴 것:
  - `inject`: 교관 대결로 상황 던지기
  - `scene_place`·`scene_day`: 장소와 시간대
  - `route`: 가짜 내비 경로
  - `ask_pcm`: 녹음 파일로 질문하기. 맥의 `say -v Yuna` 합성 음성을 16 kHz PCM으로 바꿔 넣었어요
- 파일 이름 끝: `land`는 가로 창, `day`·`night`는 시스템 테마, `dusk`는 장면 시간대가 해 질 녘이라는 뜻이에요.

## C. 가는 길 미리 연습
