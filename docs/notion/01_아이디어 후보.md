## 1. 카시트 달래기 — 아기 울음 대응 자동 루틴

> 🗣️ "6개월 아기 카시트 나오고 싶어서 엄청 울고 난리쳐도 주행 중엔 빼면 안 되는 거 아냐..?" — Threads, 댓글 216·공유 249

- **문제**: 주행 중 아기가 울어도 손을 쓸 수 없음. 답글은 전부 "노래 틀어라, 창문 열어라, 백색소음" 같은 수동 팁.
- **경험**: "아기 운다" 한마디(또는 스티어링 버튼) → 백색소음·자장가, 앰비언트 라이트 호흡 리듬, 공조 조정, 엄마·아빠 녹음 목소리 재생. 안 되면 다음 수단으로 자동 에스컬레이션. 다음 휴게소까지 거리 안내.
- **왜 차**: 손 못 쓰는 상황에서 조명·공조·소리를 한 번에 묶을 수 있는 건 차뿐.
- **SDK**: Light(`setAmbientLightBrightnessColor`), HVAC(`setHvacFanSpeed`, `setHvacTemperature`), Seat(`getCurrentSeatOccupancy`), STT/TTS, NaviHelper
- **제약**: 뒷좌석 전용 스피커 존 API 없음 → 전체 스피커로 재생. 제어 퍼미션은 배포 시 승인 필요(근거: 아동 안전 → 설득 쉬움).
- **사업성**: 영유아 부모 타깃 명확, 카시트 브랜드 제휴.

## 2. 화면 없는 뒷좌석 놀이터 — 차창 밖을 게임판으로

> 🗣️ "나는 차에서 아이에게 영상 절대 안 보여줘. 6시간 차 타야 해서 아이패드 보여줬는데 멀미해서 토하고… 미디어 중독 증세로 차에서 내리라 해도 말 안 듣고" — Threads, 좋아요 254

- **문제**: 스크린 없는 놀이 수요는 확실한데, 부모가 운전하면서 매번 직접 진행해야 함.
- **경험**: 음성 전용 AI 게임 진행자. 지금 지나는 지역·속도·경로로 "빨간 트럭 찾기", "다음 터널까지 끝말잇기", "지금 속도 맞히기" 같은 **차창 밖 현실 기반 게임**. 아이가 말로 답하면 STT로 점수. 화면은 아예 안 켬. 남은 시간에 맞춰 라운드 길이 조절.
- **왜 차**: 게임 소재가 "지금 이 차가 어디를 어떻게 달리는지". 폰 게임은 이걸 모름.
- **SDK**: STT/TTS, FusedLocation, NaviHelper(남은 시간), Odometer, 속도 — 전부 조회(get)만
- **제약**: 거의 없음. 음성 전용이라 주행 규제에 안 걸리고, 공식 Kids 카테고리 있음. 제어 퍼미션 불필요.
- **사업성**: "스크린 타임 대체재" 포지셔닝 선명. 지역 관광 콘텐츠 제휴로 확장.

## 3. 초보운전 코파일럿 — 옆자리의 운전 잘하는 친구

> 🗣️ "혼자 운전 언제쯤 안 무서울까" / "주차장 내려가거나 올라갈 때 내가 긁은 건가?" / "운전석 밑에서 이게 나왔는데 도대체 뭘까?"(좋아요 269·댓글 121) — Threads

- **문제**: 초보는 차도 모르고 상황도 모름. 피드백 받을 곳이 없음.
- **경험**: 출발 전 경로상 긴장 구간(합류, 좁은 주차장, 회전교차로) 예고 → 진입 직전 짧은 코칭. R단 전환 시 주차 단계 안내. 경고등·모르는 부품은 음성으로 묻고 답함. 주차 후 "급제동 2회, 합류 잘했어" 리포트.
- **왜 차**: 폰 코칭 앱은 페달·기어·경고를 못 봄.
- **SDK**: Brake, TurnSignal, Safety, DrivingMode, NaviHelper, STT/TTS
- **확인 필요**: NaviHelper가 **턴 단위 선행 안내 정보**까지 주는지. 안 주면 자체 지도 데이터로 보완해야 해서 난이도 상승.
- **사업성**: 신규 면허·장롱면허 탈출자. 운전연수 일부 대체, 보험사 초보 할인 연계.

## 4. 하이웨이 라디오 — 같은 길 달리는 사람들의 공동 방송

> 🗣️ "장거리 운전 2주째인데 다들 시간 어떻게 보내?? 노래랑 먹는 거 말고 좋은 방법 없을까?" — Threads

- **문제**: 혼자 장거리 운전의 지루함. 트럭 기사들이 무전기로 해온 걸 일반 운전자에게.
- **경험**: 같은 고속도로·같은 구간·같은 방향 차들끼리 음성 메시지 라디오. "앞에 사고", "휴게소 호두과자 품절", 수다. AI DJ가 큐레이션해서 TTS로 읽어줌. 구간 벗어나면 채널 자동 전환.
- **왜 차**: "지금 같은 도로에 있다"는 조건 자체가 차량 위치·경로 데이터로만 성립.
- **SDK**: FusedLocation, NaviHelper, STT/TTS + 자체 서버
- **리스크**: Social/Communication 카테고리 주행 중 메시징 심사, 악용 필터링, 초기 유저 없으면 빈 채널(네트워크 효과). 창의성 점수는 최상.

## 5. 맥락 기반 음악 추천 — 지금 이 길에 맞는 노래 (주인 원안)

> 📝 원안: 카메라·온도 센서로 운전자 정면 시야를 실시간 분석 → 분위기·날씨·온도·상황을 맥락으로 파악해 노래 추천·재생, 사용자 취향으로 보정.
>
> 보류 이유: Vehicle SDK에 카메라 도메인 없고 하드웨어 직접 접근 금지 → 시야 분석은 불가. 카메라 빼고 다른 신호로 맥락을 잡는 버전으로 재정리.

- **문제**: 날씨·시간·상황이 바뀌어도 플레이리스트는 그대로. 운전 중엔 곡 고르기도 어렵고 위험함.
- **경험**: 비가 오기 시작하면(와이퍼 ON) 잔잔한 곡으로, 터널·밤엔 분위기 전환, 스포츠 모드면 템포 업. 노래 분위기에 맞춰 앰비언트 라이트 색도 같이 바뀜. 도착까지 남은 시간에 맞춰 플레이리스트 길이 구성, 도착 직전 클라이맥스 곡. 스킵·좋아요로 취향 보정.
- **맥락 데이터 (카메라 대체)**:

| 맥락 | 데이터 소스 |
| --- | --- |
| 비·눈, 강도 | Wiper 상태·속도 |
| 밤·터널 | Light(헤드라이트) + 시간 |
| 실내 온도 | HVAC |
| 날씨·계절·지역 | FusedLocation + 외부 날씨 API |
| 출퇴근·여행·정체 | NaviHelper 목적지·남은 시간 + 요일·시간 |
| 운전 텐션 | DrivingMode(스포츠/에코) |

- **왜 차**: 아래 두 개는 폰으로 불가능. ① 차량 신호(와이퍼·라이트·드라이브 모드) 기반 실시간 전환 ② 앰비언트 라이트 연동(`setAmbientLightBrightnessColor`)
- **강점**:
  - 공모전 예시 주제 "인카 엔터테인먼트: 주행 맥락과 결합된 몰입형 미디어·사운드 경험"과 거의 일치
  - Music/Audio 카테고리는 주행 중 스트리밍·재생 조작 공식 허용 → 주행 규제 리스크 낮음
  - 데모 임팩트: Virtual Console에서 와이퍼를 켜면 조명과 노래가 동시에 바뀌는 장면
- **리스크**:
  - 음원 라이선스. 공모전에선 추천 엔진 + 무료 음원(또는 기존 스트리밍 앱으로 넘기기)로 데모
  - "멜론 무드 플레이리스트랑 뭐가 달라?"에 답해야 함 → 차량 신호 실시간 전환 + 조명 연동 + 도착 시간 맞춤 구성
  - 사용자 리서치 근거가 아직 없음(야간 조명 설렘 글 1건 정도) → 추가 리서치 필요
- **사업성**: 음원 플랫폼 제휴, 자동차 브랜드별 사운드 테마.
