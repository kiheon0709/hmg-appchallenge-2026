## 핵심 전략 메모

- 가산점은 영상 < GitHub < APK 순으로 단계별. 서류만 낸 팀과 APK까지 낸 팀은 다른 리그.
- 합격 후 PT까지 열흘뿐 → 1차 산출물을 고도화하는 구조. 1차 산출물은 2차 전까지 자유롭게 보완 가능.
- 기능 수보다 **차량 신호 하나 들어왔을 때 앱이 반응하는 장면 한 컷**이 깔끔한 게 중요. Virtual Console로 신호를 찍으면서 시연.
- 심사 4축: 차량특화성 · 창의성 · 기술활용성 · 사업성. 가장 무게 실리는 질문은 "왜 폰이 아니라 차여야 하는가".
