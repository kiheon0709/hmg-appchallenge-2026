## GitHub·APK 규칙

- APK는 파일 첨부가 아니라 **GitHub 링크**로
- 저장소 `apk/` 폴더에 업로드, 파일명 `팀명_앱이름_release.apk`
- 실행 가능한 **release** 빌드
- 용량 초과 시 GitHub Releases 등록 후 Release 링크 제출
- Private 가능 → 심사용 계정 Collaborator 초대 (쓰기 권한도 부여되니 주의), 마감 전 접근 확인
- README 필수: 앱 이름·한 줄 소개, 실행 방법, 테스트 환경·필요 설정, APK 위치 또는 Release 링크
