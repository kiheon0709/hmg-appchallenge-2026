# 초보 운전자가 어려워하거나 처음 겪어 당황하는 상황

조사일: 2026-11-15. 옆자리(SideSeat)의 훈련 상황과 "가는 길 미리 연습"을 다시 점검하려고 조사했어요. 점검 결과는 `2026-11-15_feature-gap-review.md`에 있어요.

기존 리서치(`2026-11-12b_senior-novice-pet-commute.md` 3-3, `2026-11-12b_parents-women-drivers.md` 3-2, `2026-11-12_driver-research.md` 3-8·3-13)에 이미 실린 글은 다시 싣지 않았어요. 기존 문서가 다룬 것은 합류·비보호·회전교차로·골목(인스티즈), 차로가 갑자기 좌회전 전용으로 바뀜, "민폐" 위축감, 지하주차장 진입로, 대형 SUV로 좁은 길, 오토라이트·김서림이에요.

## 읽기 전에

| 표기 | 뜻 |
| --- | --- |
| [원문] | 글이나 자료 본문을 직접 열어 확인했어요 |
| [초록] | 논문 초록을 직접 열어 확인했어요 |
| [언론] | 기관 자료를 인용한 기사 본문으로 확인했어요 |

| 충분 / 부분 / 없음 | 올바른 대처의 공식 근거 수준. 법령이나 공공기관 원문이 있으면 충분, 일부만 있거나 제조사 설명서뿐이면 부분, 찾지 못했으면 없음 |
| SS n | `docs/plan/safety-sources.md`의 n번 항목 |

- "급발진"이라는 말은 쓰지 않고 "의도치 않은 가속"이라고 적었어요.
- 빈도·강도(높음·중간·낮음)는 찾은 글 수, 조회·댓글 규모, 표현의 세기(회피, 사고, 울음)를 보고 조사자가 판단했어요.

### 1-3. 한계

- **커뮤니티 표본은 편향돼요.** 글을 쓰는 사람은 겁이 많거나 사고를 낸 사람이고, 클리앙·82cook 비중이 커요. 82cook 글 일부는 2009~2015년이라 전자식 주차 브레이크·버튼 기어 이전 경험이 섞여 있어요(표에 연도를 적었어요).
- **인용 문구는 요약 모델을 거쳐 읽었어요.** 띄어쓰기·오탈자 수준에서 원문과 다를 수 있어요. 기획서에 그대로 옮기기 전에 URL에서 한 번 대조해야 해요.
- **네이버 블로그·카페, Threads, 유튜브를 못 봤어요.** 초보 운전 후기가 가장 많이 쌓이는 곳이라 빈도 판단이 낮게 잡혔을 수 있어요.
- **초보 한정 통계가 거의 없어요.** 고속도로, 악천후, 요금소, 합류부, 회전교차로, 우회전, 어린이 보호구역은 전체 운전자 기준 수치만 있어요. 면허 1년 미만 운전자의 법규위반·도로형태·시간대·기상별 분포는 TAAS에서 직접 조건을 걸어 조회해야 하는데 화면을 읽지 못했어요.
- **"초보"의 정의가 자료마다 달라요.** 면허 1년 이하(2009 논문), 2년 미만(경찰청), 보험 가입 1년 미만(현대해상). 섞어 쓰지 않았어요.

### 3-9. 예상 밖으로 나온 것

1. **잘못 든 직후의 대응이 사고 원인으로 반복돼요.** 장소가 아니라 "멈추거나 후진하는 행동"이 문제로 지목돼요.
2. **긁은 직후 놀라서 2차 사고.** 첫 접촉보다 놀란 직후가 위험하다는 신호예요.
3. **사이드미러의 빗방울.** 폭우 글 세 곳에서 차선보다 먼저 나와요. 차로 변경을 못 하게 만드는 직접 원인이에요.
4. **운전자 보조 경고가 당황을 키워요.** 사각지대 경고음에 놀라 우왕좌왕했다는 글(블라인드 qZgBQO2f).
5. **운전 연수 차는 늘 시동이 켜져 있어서** 시동 거는 법을 모른 채 카셰어링을 빌려요.
6. **초보운전 표시의 역효과**를 말하는 댓글이 있어요.
7. **첫 사고 글의 질문은 현장 조치보다 보험(대인 접수, 할증, 사설 견인차) 쪽이 많아요.**
8. **합류 구간에서 본선 끝 차로가 안전하다는 믿음**이 틀렸던 경험.
