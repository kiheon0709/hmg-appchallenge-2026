# 옆자리 (SideSeat) — 앱 프로젝트 소개

공모전 접수양식(기획서) 초안. 항목 순서는 접수양식을 따른다. `[실측 후 갱신]` 표시는 개발 세션의 실측이 끝나면 숫자와 캡처로 바꾼다. 제품 상세는 `product-spec.md`, 대처 절차 출처는 `safety-sources.md`.

팀: MoodLab / 대학생 부문

---

## 1. 앱 한 줄 소개

**처음 타는 차, 혼자 하는 운전. 옆자리에 운전 잘하는 선배가 앉아요.**

세워 둔 진짜 차에서 진짜 스위치로 돌발 상황을 미리 겪어 보고, 달릴 때는 차가 아는 것을 한 문장으로 말해 주고, 도착하면 오늘 운전을 같이 돌아보는 초보 운전자용 훈련·코칭 앱이에요.

## 2. 기획 배경

### 2-1. 시작은 우리 이야기

> 면허 딴 지 1년. 부모님 차를 처음 빌려 몰던 날 비가 왔어요. 터널을 나오자 앞유리가 뿌옇게 됐는데, 버튼이 어디 있는지 몰랐어요. 옆자리엔 아무도 없었어요.

대학생은 자기 차가 없어요. 부모님 차, 카셰어링, 렌터카처럼 **탈 때마다 낯선 차**를 몰아요. 면허는 있지만 이 차의 성에 제거 버튼이 어디 있는지, 이 경고등이 무슨 뜻인지 몰라요. 그리고 옆에서 말해 줄 사람이 없어요.

### 2-2. 우리만의 문제가 아니에요

| 불편 | 근거 |
| --- | --- |
| 비 오는 날 전조등·후미등이 꺼진 줄 모르고 달려요 | 클리앙 굴러간당(2026-09-01, 조회 3,865·댓글 41): "끄고 달리는 게 아니라 꺼진지 모르는 겁니다" |
| 앞유리가 갑자기 뿌옇게 되는데 대처를 못 해요 | 클리앙(2024-11-09, 조회 7,841·댓글 25): "불과 20초 만에 앞이 아예 보이지 않을 정도". 같은 진단의 글이 3건 반복 |
| 초보는 밤·비·합류가 무섭고 물어볼 곳이 없어요 | 인스티즈(2025-10-15, 조회 28,729): "합류구간이 초보 때 진짜 무서워요". 인스티즈(2026-09-18, 조회 19,063): 비 오는 밤 차선이 안 보임 |
| "민폐"라는 위축감 때문에 운전을 피하다 장롱면허가 돼요 | 당근 동네생활(조회 1,740·댓글 42): "다른 차들한테 너무 죄송하고 답답해요" |
| 차 기능이 많은데 쓰기 어려워요 | J.D. Power 2025 중국 TXI(38,752명): 스마트 콕핏 불만 1위가 "이해하기·쓰기 어렵다"(36%) |

- 아반떼는 20~30대 구매 1위 차종이고(현대차 데이터, 2026-04 보도) 카셰어링의 대표 차종이에요. **Pleos Connect가 들어간 차를 처음 만나는 사람은 초보일 가능성이 높아요.**
- **낯선 차를 모는 20대가 실제로 위험해요.** 도로교통공단이 2020~2024년 8월 교통사고 84,742건을 분석한 결과, 렌터카 사고에서 20대 운전자 비중이 26.3%로 가장 높았고, 렌터카 사고 사망자의 44.0%가 20대 운전자 사고였어요. 야간 렌터카 사고에서는 20대가 50.9%예요. 공단은 운전 경력이 짧은 영향으로 분석했어요(2025-08-08 보도).
- 렌터카 업계는 면허 취득 1년 미만에게 대여를 제한하는 자체 규정을 둘 만큼 초보의 미숙을 위험으로 봐요. 그런데 **익숙해질 방법은 주지 않아요.**
- 빗길·야간·졸음 관련 공식 수치와 대처 절차의 출처는 `safety-sources.md`에 정리했어요.

### 2-3. 지금 있는 해법의 빈틈

| 지금 있는 것 | 빈틈 |
| --- | --- |
| 취급설명서, 유튜브 | 읽고 볼 뿐이에요. 그 순간 손이 버튼을 찾아가지 못해요. 차마다 위치도 달라요 |
| 계기판 경고등 | 신호 하나에 아이콘 하나예요. "비가 오는데 전조등이 꺼져 있다"처럼 여러 신호를 엮은 상황은 말해 주지 않아요 |
| Gleo AI 같은 음성 비서 | 불러야 와요. 초보는 무엇을 물어야 하는지 몰라요 |
| 운전 점수 서비스 | 점수만 줘요. 왜 그랬는지, 어떻게 고치는지는 알려 주지 않아요 |
| 운전연수 | 연수가 끝나면 혼자예요 |

조종사는 비상 절차를 시뮬레이터에서 몸으로 익혀요. 운전자에게는 그런 곳이 없어요. **옆자리는 세워 둔 내 차를 시뮬레이터로 만들어요.**

## 3. 앱 주요 기능 및 차량 특화 요소

차의 상태가 모드를 정해요. 사용자는 모드를 고르지 않아요.

### 3-1. 정차 중: 위기 상황 훈련

- 화면에 운전석 시점의 주행 화면이 달리고, 돌발 상황이 터져요.
- 운전자는 **실제 스위치**로 대처해요. 진짜 와이퍼 레버를 올리면 화면 속 폭우가 닦이고, 진짜 성에 제거 버튼을 누르면 뿌연 앞유리가 걷혀요.
- 실내 조명이 위기 때 빨갛게, 해결하면 초록으로 바뀌고, 빗소리와 천둥이 차량 스피커로 나와요.
- 해야 할 조작이 체크리스트로 보이고 초시계가 돌아요. 끝나면 "김서림 대응 3.8초, 별 3개"와 그 스위치가 이 차 어디에 있는지 알려 줘요.

| 훈련 상황 | 실제로 하는 조작 | 읽는 차량 신호 |
| --- | --- | --- |
| 폭우로 시야 상실 | 와이퍼 올리기, 전조등 켜기 | 와이퍼 스위치, 하향등 |
| 앞유리 김서림 | 성에 제거, 에어컨, 외기 전환 | 공조 상태 |
| 앞차 급정거 | 브레이크 밟기(반응 시간 측정) | 브레이크 페달 |
| 터널 진입 | 전조등 켜기 | 하향등, 상향등 |
| 짙은 안개 | 전조등 켜기, 브레이크로 속도 절반까지 줄이기 | 하향등, 브레이크 페달 |
| 맞은편 눈부심 | 상향등 끄기 | 상향등 |
| 고속도로 고장 정차 | 대처 순서를 말로 답하기(비상등 → 트렁크 → 대피 → 신고) | 음성 인식 |
| 타이어 공기압 경고등 | 뜻을 말로 답하고 조치 고르기 | 음성 인식 |
| 의도치 않은 가속 | 브레이크를 떼지 않고 계속 밟기 | 브레이크 페달 |
| 졸음 | 외기 전환, 창문 열기 | 공조, 창문 |
| 내리기 전 점검 | 등화 끄기, 창문 닫기, 주차 브레이크는 말로 확인 | 등화, 창문, 음성 인식 |

**에뮬레이터 실측**: 훈련 상황 11개 중 9개가 실제 차량 신호로 판정돼요(폭우, 김서림, 급정거, 터널, 안개, 눈부심, 졸음, 의도치 않은 가속, 내리기 전). 고장 정차와 경고등은 말·선택으로 답해요. 장면 캡처는 저장소 `docs/screens/sim/`에 있어요.

- 챕터: "첫 빗길", "밤 고속도로", "멈춰야 할 때", "내리기 전에". 무작위로 터지는 돌발 모드, 조수석 친구가 상황을 던지는 교관 대결.
- **이 차 면허**: 차종별로 챕터를 모두 깨면 "이 차 숙련" 배지를 줘요. 다른 차를 타면 다시 따요.
- 모든 대처 절차는 도로교통공단, 한국교통안전공단, 한국도로공사 등 공식 자료를 근거로 해요.

### 3-2. 주행 중: 한 문장 코치

- 여러 신호를 엮어야만 알 수 있는 것만, 한 번에 한 문장으로 말해요.
  - 와이퍼가 켜져 있는데 전조등이 꺼져 있으면: "비가 와요. 전조등을 켜 주세요."
  - 비 오는 날 내기순환이 오래 이어지면: "앞유리에 김이 설 수 있어요. 외기로 바꿔 보세요."
  - 상향등이나 깜빡이가 오래 켜져 있으면 알려 줘요.
  - 정차·주행 판정은 Pleos 가이드가 안내하는 주행 규제 상태로 해요.
  - 두 시간 가까이 달리면 휴게소를 권하고, "응" 한마디에 내비 경유지로 넣어요.
- 훈련에서 연습한 상황이 실제로 오면 "연습했던 거예요"라고 이어 줘요.
- 말수를 제한해요(30분에 3번까지). 화면은 거의 비워요. 주행 중에는 차를 제어하지 않고 말로만 권해요.

### 3-3. 도착 후: 같이 돌아보기

- 주차하면 오늘 주행을 30초로 정리해 말해 줘요. 잘한 것 하나, 고칠 것 하나, 다음에 해 볼 훈련 하나.
- "왜 외기로 바꿔야 해?"처럼 되물으면 답해요.
- 평가하지 않아요. 점수 대신 "지난번보다"로 말해요.

### 3-4. 보너스: 친구들과 미니게임

- 핸들을 돌려 금고 다이얼을 맞추는 게임 등, 차의 조작 장치가 컨트롤러가 되는 정차 중 게임이에요.

### 3-5. 왜 차에서만 가능한가

| 요소 | 모바일로는 안 되는 이유 |
| --- | --- |
| 입력이 실제 스위치 | 와이퍼 레버, 성에 제거 버튼, 브레이크, 핸들을 읽을 수 있는 건 차뿐이에요 |
| 신호 조합 코칭 | 와이퍼·등화·공조·착좌를 동시에 아는 건 차뿐이에요 |
| 정차·주행에 따른 모드 전환 | 차의 주행 상태가 화면과 기능을 바꿔요 |
| 실내 연출 | 앰비언트 조명과 차량 스피커가 훈련의 일부예요 |
| 차종별 숙달 | 스위치 위치는 차마다 달라요. 그 차 안에서 익혀야 해요 |

## 4. 주요 사용 시나리오

### 시나리오 1. 부모님 차를 처음 빌린 날 (대학생 민지)

1. 민지가 부모님의 그랜저에 처음 앉아요. 옆자리 앱이 "이 차는 처음이시네요. 출발 전에 3분만 같이 해 볼까요?"라고 물어요.
2. "첫 빗길" 챕터가 시작돼요. 화면 속 고속도로에 비가 쏟아지고 실내 조명이 빨갛게 바뀌어요.
3. 민지가 와이퍼 레버를 찾아 올려요. 6.1초. "와이퍼 레버는 핸들 오른쪽이에요. 다음엔 더 빨리 찾을 거예요."
4. 터널을 나오자 화면이 뿌옇게 돼요. 민지는 버튼을 못 찾아요. 선배가 "공조 패널의 앞유리 모양 버튼이에요"라고 알려 줘요. 누르자 김이 걷혀요.
5. 일주일 뒤 실제로 비가 와요. 와이퍼를 켜자 선배가 말해요. "연습했던 거예요. 전조등도 켜 주세요."
6. 도착 후: "오늘 비 오는 길을 20분 달렸어요. 전조등은 알려 드린 뒤 3초 만에 켰어요."

### 시나리오 2. 카셰어링으로 친구들과 떠나는 엠티

1. 쏘카 아반떼에 넷이 타요. 출발 전 휴게소에서 조수석 친구가 "교관 대결"로 운전자에게 돌발 상황을 던져요.
2. 운전자가 "밤 고속도로"를 깨자 금고 다이얼 미니게임이 열려요. 핸들을 돌려 금고를 여는 걸로 내기를 해요.
3. 주행 중 두 시간이 가까워지자 "다음 휴게소에서 쉬어 갈까요?" → "응" → 내비에 경유지가 추가돼요.
4. 차를 반납하기 전 "내리기 전에" 챕터가 전조등, 창문, 주차 브레이크를 같이 확인해요.

### 시나리오 3. 10년 장롱면허를 꺼낸 날

1. 주차장에 세워 둔 차에서 며칠에 걸쳐 챕터를 하나씩 깨요. 도로에 나가기 전에 손이 먼저 익어요.
2. 첫 주행. 선배는 꼭 필요한 한 문장만 말해요.
3. 도착 후 리뷰가 "지난번보다 급하게 밟은 브레이크가 줄었어요"라고 말해 줘요.

## 5. 개발 계획

### 5-1. 구조

```
┌─ 화면 (Jetpack Compose) ─────────────────────────────┐
│ 홈 · 훈련(가짜 3D 주행 화면) · 결과 · 코치 · 리뷰 · 미니게임 │
└───────────────▲─────────────────────────────────────┘
                │ 상태
┌─ 앱 상태 기계 ─┴──────────────────────────────────────┐
│ 정차/주행 판정 → 모드 전환, 포그라운드 서비스(주행 코치)   │
└──▲──────────────▲──────────────────▲────────────────┘
   │ 차량 상태      │ 이벤트             │ 문장
┌──┴─────────┐ ┌──┴───────────────┐ ┌─┴──────────────────┐
│ 차량 계층    │ │ core (순수 로직)   │ │ 음성 계층            │
│ Vehicle     │ │ 훈련 엔진·점수      │ │ Pleos TTS / STT     │
│ NaviHelper  │ │ 코치 규칙·말수 제한 │ │ AI 교관(LLM, 텍스트) │
│ FusedLocation│ │ 미니게임           │ │ 효과음              │
└─────────────┘ └──────────────────┘ └────────────────────┘
```

- 판정·점수·코치 규칙은 안드로이드에 의존하지 않는 순수 로직으로 분리하고 자동 테스트로 고정해요(핵심 로직 테스트 77개, 음성 로직 테스트 56개 통과).
- 주행 화면은 3D 엔진 없이 2.5D로 그려요(가벼워서 정차 중 리소스 기준 안에 들어와요). 에뮬레이터에서 60fps로 돌아요(평균 16.7ms, 33ms를 넘는 프레임 0). CPU·메모리 측정은 2차 PT 전에 추가해요.

### 5-2. SDK 사용 계획

| SDK | 쓰는 API (대표) | 쓰는 곳 |
| --- | --- | --- |
| **Vehicle** (읽기) | 와이퍼 스위치·상태, 하향등·상향등 상태, 방향지시등, 공조(성에 제거·에어컨·내기순환), 브레이크 페달, 조향각, 창문 위치, 착좌, 차량 정보 | 훈련 판정, 주행 코치의 신호 조합, 미니게임 입력 |
| **Vehicle** (제어) | 앰비언트 조명 색·밝기 | 정차 중 훈련의 실내 연출 |
| **TextToSpeech** | `speak(text, isFinal)` 조각 재생 | 선배의 모든 말, LLM 응답의 문장 단위 스트리밍 |
| **SpeechToText** | `request()`, 중간 결과 `onUpdated` | 대답(응/아니), 질문, 훈련 중 말로 답하기 |
| **NaviHelper** | 남은 시간, 도착 이벤트, 경유지 추가 | 리뷰 시점, 휴게소 경유 |
| **FusedLocation** | 위치·방향 | 일몰 시각 계산, 속도 추정(급감속 관찰) |

- 허용된 5종을 모두 핵심 기능에 써요. 공개 문서 범위의 API만 써요.
- 가용성은 차종 이름이 아니라 `checkXXXCapabilities`와 `isSupported`로 확인하고, 없는 신호가 필요한 상황·규칙은 자동으로 빼요.
- 음성 인식은 Pleos STT만 써요. 차량 마이크 음성은 밖으로 보내지 않고 인식된 텍스트만 다뤄요.

### 5-3. 핵심 기술

1. **실제 스위치 ↔ 화면의 실시간 연동**: 신호 변화가 화면에 바로 보이도록 구독과 주기 조회를 섞어요(와이퍼 스위치는 단계 변화 알림이 없어 주기 조회). 실측 지연은 브레이크·등화·공조·창문 10ms 미만, 조향각 90~160ms, 와이퍼 단계 30~160ms예요.
2. **음성 지연 줄이기**: 듣는 동안 답을 준비하고, 짧은 대답은 앱 규칙으로 즉시 처리하고, LLM 응답은 문장 단위로 끊어 바로 말해요. 실측: 음성 인식이 끝난 뒤 첫 음성까지, 앱 규칙으로 답하는 빠른 길은 6~8ms, LLM을 거치는 길은 0.94초예요(음성 인식 자체가 말 끝 뒤 약 0.4초에 결과를 줘요).
3. **말수 제한과 우선순위**: 안전 규칙이 먼저, 30분에 3번까지, 내비 안내·통화·Gleo가 말할 때는 기다려요.
4. **안전한 AI 교관**: 공식 출처에서 만든 지식 안에서만 답해요. 네트워크가 끊겨도 규칙 기반으로 전부 동작해요.
5. **주행 규제 준수**: 훈련·게임·애니메이션은 정차 중에만. 주행으로 바뀌면 즉시 닫고 한 줄 화면으로.

### 5-4. 구현 현황

Pleos Connect Emulator 2.1.0에서 Virtual Console 조작으로 확인했어요(기록: 저장소 `docs/STATUS.md`).

## 6. 기대효과 및 발전 가능성

### 6-1. 기대효과

- **운전자**: 낯선 차에서 그 순간 손이 스위치를 찾아가요. 혼자 운전해도 덜 무서워요.
- **Pleos 생태계**: App Market의 현재 앱은 내비·음악·영상 같은 모바일 서비스 이식이에요. 옆자리는 차량 데이터가 없으면 존재할 수 없는 앱이고, 확대 예정 카테고리(차량 관리·게임·라이프스타일)의 첫 사례가 될 수 있어요.
- **제조사**: 신차의 기능을 고객이 놀면서 익혀요("쓰기 어렵다"는 불만의 해법).

### 6-2. 타깃과 규모

- 1차: Pleos Connect 탑재 차를 타는 초보·청년 운전자, 카셰어링·렌터카 이용자.
- 규모를 가늠할 공개 수치
  - 20대 이하 신규 운전면허 취득자: 2024년 45만 2,463명(경찰청 자료, 2025-09 보도). 해마다 이만큼의 초보가 새로 생겨요.
  - 쏘카 회원 400만 명(2026-09 보도), 차량 약 2만 5천 대. 카셰어링은 "처음 타는 차"가 매번 반복되는 곳이에요.
  - Pleos Connect 적용 계획: 2030년까지 약 2천만 대(현대차그룹 발표).
- 초기 목표: Pleos 탑재 아반떼·그랜저 이용자 중 초보·청년층과 카셰어링 이용자. 예상 MAU와 계산 근거는 2차 PT 전에 카셰어링 이용 통계로 보강해요. `[갱신: 계산식]`

### 6-3. 재방문

- 정차할 때마다 1분 훈련, 주행할 때마다 리뷰. 계절·날씨에 맞춘 "오늘의 미션"(비 예보가 있는 날 출발 전 빗길 1분).
- 차를 바꿔 탈 때마다 "이 차 면허".
