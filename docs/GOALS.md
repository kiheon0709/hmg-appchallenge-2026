## 현재 제약

- 클라우드에서 Android SDK·AGP(`dl.google.com`) 접근 차단 → app 모듈은 컴파일 검증 불가. 환경 설정에서 `dl.google.com`, `maven.google.com`을 허용 도메인에 넣으면 다음 세션부터 빌드 가능.
- Pleos 문서·SDK(`document.pleos.ai`, `nexus-playground.pleos.ai`) 차단 → SDK 연결은 맥에서.
