- 2차 PT 심사 대상 팀은 PT 심사 전까지 실제 동작 가능한 앱 개발을 완료해야 합니다.

### GitHub 저장소 제출 안내
GitHub 저장소에 소스 코드와 APK 파일을 함께 업로드해 제출해 주세요.
#### 제출 방법
- 새 GitHub 저장소를 만들거나 기존 개발 저장소를 사용합니다.
- 프로젝트 소스 코드를 저장소에 업로드합니다.
- APK 파일은 저장소 내 apk/ 폴더에 업로드합니다.
- 저장소 주소와 APK 파일 경로를 제출 페이지에 입력합니다.
#### APK 파일명
팀명_앱이름_release.apk
#### 제출 전 확인해 주세요
- APK는 실행 가능한 release 버전으로 제출해 주세요.
- APK 파일이 GitHub 업로드 용량을 초과하는 경우, GitHub Releases에 등록한 후 해당 Release 페이지 주소를 제출해 주세요.
- 비공개(Private) 저장소도 제출할 수 있습니다. 심사용 계정을 Collaborator로 초대하실 필요는 없습니다.
- 접수 메일에 저장소 주소와 최종 커밋 번호(commit hash)를 적어 주세요. 심사는 이 커밋 기준으로 진행합니다.
- 비공개 저장소는 접수 마감 후 11월 16일(월)까지 공개(Public)로 전환하고, 1차 심사 결과 발표일(11월 23일)까지 공개 상태를 유지해 주세요. 공개로 전환되지 않으면 개발 산출물 가산점이 반영되지 않습니다.
- 저장소 공개가 어려운 경우에는 소스 코드와 APK를 압축한 파일의 내려받기 주소를 접수 마감 전까지 접수 메일로 보내 주셔도 됩니다.
- README.md에는 아래 내용을 작성해 주세요.
- 앱 이름 및 한 줄 소개
- 실행 방법
- 테스트 환경 및 필요한 설정
- 개발에 사용한 Pleos Connect 에뮬레이터 버전과 화면 규격
- APK 파일 위치 또는 GitHub Release 링크
