## 참가 자격 · 팀
### 팀으로 참가할 수 있나요?
개인 또는 최대 5인 팀으로 참가할 수 있습니다.
대표자와 팀원 전원이 각각 개인정보 수집·이용 동의서에 동의 여부, 서명과 날짜를 작성하고, 대표자가 팀원 전원을 참조수신(CC)하여 이메일로 제출합니다.
### 누가 참가할 수 있나요?
대학(원)생 · 일반인 · 스타트업이 개인 또는 팀으로 참가할 수 있습니다.
시상 부문은 대학생 / 일반(스타트업 포함)입니다.
### 팀으로 참가하려면 어떻게 접수하나요?
대표자와 팀원 전원의 성명, 소속, 휴대폰번호, 이메일 주소를 접수양식에 기입합니다.
모두 개별 동의·서명·날짜를 작성한 후 대표자가 팀원 전원을 CC하여 appdevchallenge@hyundai-partners.com으로 제출합니다.
## 접수 · 제출물
### 제출 후에 수정할 수 있나요?
제출한 내용을 수정하려면 마감 전까지 처음 제출한 이메일 주소로 수정된 자료를 다시 보내주세요.
여러 번 제출한 경우, 마감 전 마지막으로 제출한 자료를 최종본으로 심사합니다.
수정 제출 이메일 제목은 [수정제출] [차량용 앱 개발 공모전] 팀명(개인은 성명)_대표자명입니다.
수정 제출 시에도 전체 제출 자료와 서명한 동의서를 모두 첨부하고, 팀원 전원을 참조(CC)해 주세요.
### 어떤 파일을 내야 하나요?
작성한 접수양식이 곧 기획서입니다.
시연 영상, GitHub 저장소, APK 등 개발 산출물은 선택 제출이며 함께 제출하면 단계별 가산점을 부여합니다.
APK 파일만 따로 제출하지 않고, GitHub 저장소에 소스 코드와 APK 파일을 함께 업로드해 제출해 주세요.
숏폼 링크는 접수양식(기획서)에 기재해 이메일로 함께 제출하며, 선택 제출입니다.
2차 PT 심사 대상 팀은 PT 심사 전까지 실제 동작 가능한 앱 개발을 완료해야 합니다.
### 기획서만으로도 지원할 수 있나요?
- 네.
접수양식(기획서)만으로 지원할 수 있습니다.- 개발 산출물(시연 영상, GitHub 저장소 등)은 필수제출사항은 아니지만, 추가 제출시 가산점이 부여됩니다.- 다만 2차 PT 심사 대상 팀은 PT 심사 전까지 실제 동작 가능한 앱 개발을 완료해야 합니다.
### 비공개 GitHub 저장소도 제출할 수 있나요?
- 비공개(Private) 저장소도 제출할 수 있습니다.
심사용 계정을 Collaborator로 초대하실 필요는 없습니다.- 접수 마감(11월 15일 23:59)까지는 저장소를 비공개로 두셔도 됩니다.
접수 메일에 저장소 주소와 최종 커밋 번호(commit hash)를 적어 제출해 주세요.- 접수 마감 후 11월 16일(월)까지 저장소를 공개(Public)로 전환하고, 1차 심사 결과 발표일(11월 23일)까지 공개 상태를 유지해 주세요.- 심사는 11월 16일부터 접수 메일에 적힌 최종 커밋 기준으로 진행합니다.
공개로 전환되지 않으면 개발 산출물 가산점이 반영되지 않습니다.- 저장소 공개가 어려운 경우에는 소스 코드와 APK를 압축한 파일의 내려받기 주소를 접수 마감 전까지 접수 메일로 보내 주셔도 됩니다.
### 접수양식은 어디서 받나요?
지원·제출 방법 페이지에서 개인정보 수집·이용 동의서가 포함된 공모전 접수양식을 내려받을 수 있습니다.
접수양식이 곧 기획서이며, 작성한 양식을 이메일로 제출합니다.
## 개발 환경 · SDK
### 개발은 어떻게 시작하나요?
Pleos Connect 환경을 이해하고, Pleos Playground 개발 문서로 아이디어를 기획한 뒤, Pleos Connect SDK로 개발합니다.
접수양식 5번(개발 계획)에는 Pleos Connect 환경에서 앱을 어떻게 구현할지, 주요 개발 범위와 SDK/API 사용계획을 구체적으로 작성해 주세요.
### 어떤 SDK와 API를 쓸 수 있나요?
Vehicle SDK, NaviHelper SDK, TextToSpeech SDK, SpeechToText SDK, FusedLocation SDK입니다.
각 SDK의 현재 제공 상태와 사용 조건은 SDK 문서 페이지에서 확인해 주세요.
### 개발 환경 요구사항은 무엇인가요?
Pleos 개발 문서의 개발 환경 요구사항 기준으로 Android API 28 이상, Gradle 8.0 이상, Java 또는 Kotlin을 사용합니다.
문서와 대응하는 SDK 버전도 같은 페이지에 있습니다.
## 심사 · 시상
### 심사 기준은 무엇인가요?
차량특화성, 창의성, 기술 활용성, 사업성 네 항목은 필수로 평가하고, 개발 산출물(프로토타입 시연 영상, 소스 코드와 APK를 포함한 GitHub 저장소 링크)은 선택 제출물로 제출 시 가산점을 부여합니다.
항목별 평가 내용은 심사·시상 페이지에서 확인할 수 있습니다.
### 시연 영상이나 GitHub 저장소를 내면 유리한가요?
1차 접수 시 시연 영상, GitHub 저장소, APK 등을 함께 제출하면 단계별 가산점을 부여합니다.
GitHub 저장소에 소스 코드와 APK 파일을 함께 업로드해 제출해 주세요.
2차 PT 심사 대상 팀은 PT 심사 전까지 실제 동작 가능한 앱 개발을 완료해야 합니다.
### 결과는 언제 발표하나요?
- 1차 서류심사 결과는 11월 23일에 발표하고, 2차 최종 PT 심사(오프라인 발표)는 12월 3일부터 4일까지, 최종 선정 결과 발표는 12월 18일입니다.- 선정작 10팀은 현대자동차그룹 행사 전시 및 시상(2027.02)에서 전시·시상하며, 이때 최종 순위를 발표합니다.- 단계별 결과 발표 내용은 공지사항을 통해 공지됩니다.
### 최종 선정된 후 전시 준비 기간 동안 무엇을 하나요?
- 최종 선정된 10개 팀은 2027.02 개최되는 현대자동차그룹 공식 행사 현장에서 앱을 직접 전시하게 됩니다.- 전시 준비 기간 동안 참가팀은 새로운 기능을 추가 개발하는 것이 아니라, 행사 부스에서 상영될 전시 영상 제작에 협조하고 현장 시연을 위한 최종 구동용 APK를 제출하여 구동 안정성 테스트를 진행하게 됩니다.
### 최종 순위(대상/최우수 등)는 언제 확정되나요?
- 최종 수상작의 순위는 2차 PT 심사에서 제출 및 시연한 결과물을 기준으로 평가하여 확정되며, 최종 순위 발표 및 시상식은 2027.02 현대자동차그룹 공식 행사 현장에서 진행됩니다.- PT 심사 이후 행사 전까지는 오류 수정 등 필요에 따른 일부 보완은 가능하지만, 추가 개발 여부가 최종 순위 평가에 영향을 미치지 않으므로 참가팀은 전시 준비와 현장 시연 안정화에 집중해 주시면 됩니다.
## 숏폼 챌린지
### 숏폼 챌린지는 무엇인가요?
숏폼 챌린지란 차량용 앱 아이디어나 시연 화면을 30초~1분 이내 세로 방향 숏폼 영상(릴스/쇼츠)으로 공유하고, SNS를 통해 대중과 소통하는 특별 참여형 이벤트입니다.
2026.10.21–2026.11.15 공모 접수 기간과 동일하게 진행합니다.
숏폼 챌린지 참여팀 중 우수한 숏폼 콘텐츠를 제작한 1팀에 50만원을 시상하고, 현대자동차그룹 행사(2027.02)에 초청됩니다.
공모전 본상과 별도이며 본상 수상 여부와 관계없이 선정될 수 있습니다.
### 숏폼 링크는 꼭 내야 하나요?
아니요.
공모전 필수 제출물은 접수양식이고, 숏폼 참여와 링크 제출은 선택입니다.
숏폼 챌린지 수상작은 별도의 상금(50만원)과 현대자동차그룹 행사 초청권이 수여됩니다.
### 숏폼은 어디에 올리나요?
참가자 개인 또는 팀 계정에 Instagram 릴스나 YouTube Shorts로 게시합니다.
필수 지정 해시태그(#HMG차량용앱개발공모전) 1개를 포함하여 총 2~3개의 해시태그를 본문 또는 설명란에 달아야 정상 참여로 인정되며, 링크는 접수양식에 기재합니다.
