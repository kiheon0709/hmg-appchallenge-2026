# Pleos Connect
새로운 이동 경험을 만드는 차세대 인포테인먼트 시스템
## 지속적으로 진화하는
Next-Generation Infotainment지속적으로 진화하는 Next-Generation Infotainment
기존의 제조사 중심적이고 일방적인 기능 제공에서 벗어나, 고객과 지속적으로 연결되고 함께 개선해 나가는 관계 중심의 경험을 구축합니다. 구매 이후에도 제품의 가치와 사용자 경험, 안전과 품질을 지속적으로 향상시키는 것이 Pleos Connect의 핵심 목표입니다. ‘Pleos Connect’는 직관적으로 설계된 인터페이스와 AI 에이전트 Gleo AI, 그리고 개방형 앱 생태계를 통해 차량 내 경험을 한층 풍부하게 만듭니다.
### Safety
안정성
Pleos Connect의 모든 인터페이스는 '안전 중심 원칙'에 따라 철저하게 설계되었습니다. 주행 중 발생할 수 있는 인지 부하와 방해 요소를 최소화하여, 고객이 오직 운전에만 집중할 수 있는 환경을 제공합니다.
### Intuition
직관성
복잡한 매뉴얼이나 별도의 학습 과정은 필요하지 않습니다. Pleos Connect는 스마트폰을 다루듯 자연스럽고 직관적인 조작 경험(Connected UX)을 지향합니다.
### Openness
개방성
Pleos Connect는 닫힌 시스템이 아닌, 무한히 확장 가능한 개방형 플랫폼입니다. 시간이 지날수록 성능이 개선되고 새로운 기능이 추가되며, 고객의 라이프스타일에 맞춰 차량의 가치가 지속적으로 성장합니다.

## 안전하고 편리한 구조로
누구나 쉽게 사용하는 인터페이스안전하고 편리한 구조로 누구나 쉽게 사용하는 인터페이스
Pleos Connect는 직관적인 디자인을 바탕으로 별도의 학습 없이도 손쉽게 다룰 수 있는 차량용 인포테인먼트 시스템을 지향합니다. 차량에 탑승하는 모든 사용자가 한눈에 정보를 파악하고 조작할 수 있도록 아이콘 크기나 폰트 두께와 같은 기본적인 요소부터, 화면 UX 레이아웃 전반에 걸쳐 심플하고 일관된 디자인을 적용했습니다. 이와 같은 설계 원칙 아래, 현대차그룹은 기존의 클러스터와 인포테인먼트 디스플레이 중심의 인터페이스를 재구성했습니다.

## 직관적인 인터페이스와 신기술 적용으로
쓰기 편한 차세대 내비게이션직관적인 인터페이스와 신기술 적용으로 쓰기 편한 차세대 내비게이션
Pleos Connect의 내비게이션은 사용자의 선택 부담을 줄이는 방향으로 새롭게 설계되었습니다. 사용자 데이터를 분석해 실제 주행 중 빈번하게 사용되는 기능 중심으로 설정을 간소화했고, 핵심 기능은 빠르고 쉽게 접근할 수 있도록 배치했습니다. 또한 단순한 색상과 심플한 아이콘 디자인을 적용해 가독성을 향상시켰습니다.

### App Market
사용자가 차량 디스플레이에 최적화된 외부 앱을 직접 설치할 수 있는 플랫폼입니다.
### Pleos Playground
외부 개발자가 차량 환경에 최적화된 앱을 기획하고 개발할 수 있도록 차량 API와 소프트웨어 개발 도구(SDK)를 제공하는 전용 플랫폼입니다.
### OTA (Over-the-Air) 업데이트
구축된 개방형 생태계를 바탕으로 무선 소프트웨어 업데이트를 지원하여, 차량 구매 이후에도 시스템 성능 개선 및 신규 서비스 추가가 지속적으로 이루어집니다.
