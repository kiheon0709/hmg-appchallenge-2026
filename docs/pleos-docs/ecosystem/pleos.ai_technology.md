## CODA OS
Vehicle OS
CODA OS는 CODA 위에서 작동하는 차량 제어용 분산형 운영체제입니다.
하드웨어 추상화 계층(VHAL)을 통한 HW/SW 디커플링으로 OTA 업데이트 및 기능 확장을 실현합니다.
표준화된 Vehicle API를 통해 모든 기능 영역이 누구에게나 개발 가능한 인터페이스로 열리게 됩니다.CODA OS는 CODA 위에서 작동하는 차량 제어용 분산형 운영체제입니다. 하드웨어 추상화 계층(VHAL)을 통한 HW/SW 디커플링으로 OTA 업데이트 및 기능 확장을 실현합니다. 표준화된 Vehicle API를 통해 모든 기능 영역이 누구에게나 개발 가능한 인터페이스로 열리게 됩니다.

## Data Flywheel
데이터 유니언을 통해 축적된 방대한 데이터는 수집·학습·가상 검증·배포가
단절 없이 이어지는 선순환 개발 구조인 Data Flywheel을 통해 고도화됩니다.
HMG는 이 체계를 바탕으로 지속적인 AI 고도화와 OTA 배포를 통해
