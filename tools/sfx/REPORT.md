# 효과음 수치 검사

`python3 tools/sfx/analyze.py`가 만든 표예요. 사람이 듣는 확인을 대신하지 않아요.

- 파일: `app/src/main/assets/sfx/` 18개, 생성 스크립트 `tools/sfx/generate.py`(코드 합성, 외부 음원 없음)
- 기준: 클리핑 |x| ≥ 0.999, 트루 피크 ≤ -1.0 dBTP, 첫·끝 샘플 ≤ -40.0 dBFS(딸깍임), 반복 이음매 비율 ≤ 1.0
- 앱 음량 = 파일 LUFS + 20·log10(SfxPlayer.GAIN). 선배가 말하거나 듣는 동안 효과음은 ×0.32 (-9.9 dB)로 줄어요(0.18초에 걸쳐).
- 반복음은 0.6초에 걸쳐 커지고, 멈출 때 0.9초에 걸쳐 작아져요. 반복 파일은 이음매를 위해 파형 중간에서 시작하므로 첫 샘플 기준은 단발음에만 적용해요.
- 앱 음량 범위: 단발음 -29.0 ~ -14.3 LUFS, 반복(배경)음 -33.9 ~ -24.7 LUFS

## 판정

- 기준을 넘는 항목 없음(클리핑 0, 트루 피크·딸깍임·이음매 모두 기준 안).

## 사람이 들어서 확인할 것

- 빗소리·천둥·타이어가 실제처럼 들리는지, 하품·숨소리가 어색하지 않은지(합성음 한계)
- 차량 스피커에서 선배 목소리와 겹칠 때 효과음이 충분히 작아지는지
- 단발음끼리 크기 차이가 거슬리지 않는지(경고음·타이어는 일부러 크게 둠)
